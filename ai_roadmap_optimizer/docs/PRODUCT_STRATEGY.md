# Product strategy

## Positioning

The differentiator is not another prioritization score. It is a transparent bridge from portfolio choices to an executable, capacity-aware sequence with scenario comparison.

## Wedge

Start with teams maintaining 10–20 candidate initiatives across a small number of delivery teams. JSON import keeps the first version vendor-neutral and testable.

## Expansion

After input quality and solver correctness are proven: CSV import, calendar periods, uncertainty ranges, saved scenarios, Jira/Linear adapters, portfolio boundaries, CP-SAT scheduling, and a grounded explanation layer that cites the exact constraints and score deltas behind each change.
